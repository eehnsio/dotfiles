# niri

Scrolling tiling compositor. Linux only.

## Caveat on a fresh machine

`config.kdl` ends with `include "dms/*.kdl"` fragments generated by DMS. They do
not exist until DMS has run once, and niri refuses to load a config with a
missing include.

## Keybinds

macOS muscle memory where possible: `Mod+W` closes, `Mod+Space` launches,
`Mod+B`/`Mod+E` open browser and files, `Mod+Shift+3/4/5` screenshot, and
`Mod+§` cycles windows within an app (see the `bin` package).

`Mod+Ctrl+R` resets a window's height back to automatic — niri keeps an
explicitly set height until told otherwise, so a window does not grow back on
its own when its neighbour closes.

## Keyboard

The layout is `se` with `nodeadkeys`, so `~ ^ \` ¨` type directly instead of
waiting for a second key. In the stock layout `AltGr+¨` is `dead_tilde`, which
prints nothing until you follow it with a space — indistinguishable from a broken
key when you are reaching for `~` mid-command.

Swedish layout note: `[` and `]` sit behind AltGr, so consume/expel is also
bound to `Mod+Å` and `Mod+¨`, the same physical keys.

## Outputs are named by EDID

`local.kdl` names outputs `"maker model serial"` rather than `DP-1`. A connector
name is a socket on the GPU, not a screen: plug a different monitor into the same
port and it inherits everything, including `transform "90"`.

No fallback needs writing. An output with no matching block gets niri's defaults,
and a block matching no connected output is ignored silently.

## What is not included

`dms/layout.kdl` and `dms/colors.kdl` are generated but deliberately left out.
layout.kdl would override `gaps 20` and re-enable the border; colors.kdl is
always empty because DMS only ever writes border *widths* to niri, never colours.
The focus ring colour is therefore set by hand.
