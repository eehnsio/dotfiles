# Chocofi Split Keyboard

36-key split keyboard (3x5 + 3 thumb keys per side) running QMK firmware, configured via [Vial](https://vial.rocks/).

## Files

- `chocofi.vil` — Vial configuration backup. Open in Vial to edit/flash.
- `LAYOUT.md` — documented keymap for all layers.

## Quick start

1. Connect keyboard via USB
2. Open [Vial](https://vial.rocks/) in browser
3. Import `chocofi.vil` or edit live
